Nestor, one block at a time

Toy illustration. The routers are small random vectors from the seed. This is not a trained Nestor checkpoint.

In a usual mixture-of-experts transformer, each token picks a few expert MLPs and attention stays dense. Nestor does the same thing to attention. A block has C columns. A router, run once at the block input, sends each token to Kc of them, and the token only attends to other tokens in those columns. Each column then has its own experts.

Controls

The paper's tied bank is larger: Es = 8 stored, Ks = 2 used.

Kc cannot exceed C, and Ke cannot exceed E. C = 1 is a plain MoE. C = 1 and E = 1 is a dense transformer.
