Call the catalog, don’t scrape the page

Simulated agents, live tools. The shop registers tools on document.modelContext. No model call, no API key, nothing leaves the tab.

Alpine Outfitters is a ten-product outdoor shop. A shopper wants trail shoes under $140 with a heel-to-toe drop of 5mm or less. One agent reads CSS classes and clicks what it finds. The other calls tools the page registered. MCP would be those tools on a server. WebMCP is this tab, with the buyer still confirming the charge.
